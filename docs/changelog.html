v3.0.0 (from v2.0.0)#

  • New: automation (flows, playbooks, gantt, autonomy, heartbeat, curiosity, lisp, secrets), notes, and senses and devices (http, mcp, senses with look, usb, backup); kit.notify(); the agent plugin hook beforeTool. Scripts can now call kit.ask, kit.agent, kit.flow, kit.flows, kit.notify and kit.kv (also as jade.*). Secrets are redacted as {{NAME}}.

v2.0.0 (from v1.0.0)#

  • createKit() no longer loads every feature. Use kit.use('…') (or createKit({ use: [...] }) / 'all') before touching kit.python, kit.sqlite, kit.webxdc, …; the async helpers load by themselves.
  • kit.agent() is async: const agent = await kit.agent({ … }).
  • createKit exports only createKit, VFS, setAssetsBase and getAssetsBase; import other classes from their module file (dist/sqlite.js, dist/bm25.js, …).
  • The scheduler starts when it is loaded (use: ['schedule'] on pages that should run saved jobs).
  • New: Sentry for the browser; the agent brain (memory, knowledge, think, delegate, skills, history, guard, router, models), agent plugins (kit.agent({ plugins })), kit.complete(), createKit({ provider, model }). The agent's done event comes after its plugins' after hooks.
