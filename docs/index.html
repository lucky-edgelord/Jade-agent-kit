Jade Agent Kit

A browser workspace for AI agents, loaded from a CDN with one import. It is lean: the core is about 6.6 KB gzipped, and each feature below is its own module that downloads only when a page uses it. It gives any web project:

  • a virtual file system (in memory, optionally kept in IndexedDB) shared by everything below
  • a shell: BusyBox 1.37 compiled to WebAssembly, with pipes, redirects, && ||, $VAR, $(…) and globs, plus JavaScript versions of the common commands as a fallback
  • MicroPython 1.27 and a Node-style JavaScript sandbox (require('fs'), local modules, node:sqlite, fetch), both in Web Workers
  • SQLite 3.53 with sqlite-vec (vector search) and FTS5
  • ranked BM25 keyword search
  • TensorFlow.js, ONNX Runtime Web and LiteRT (.tflite), on WebGPU when the device has it
  • a webxdc host for running .xdc apps in a sandboxed frame
  • LLM tool definitions (OpenAI/Ollama and Anthropic shapes) with one dispatcher
  • decisions with decision models on Ollaya, Ollama (0.35+) or Ollama Cloud: pick one, score, yes/no, with calibrated probabilities
  • Sentry: rules that watch the page and the device (battery, network, idle, keys, motion, light, location, sound level, camera change, your own states and events) and act when something happens
  • a cron scheduler (plain English or cron) for shell, JS, Python, agent or function jobs, and a task list
  • embeddings from Ollama on your machine, and a vector store on sqlite-vec (semantic and hybrid search)
  • a small pi-style agent on Ollama Cloud or Ollama on your machine, with six tools: read, write, edit, bash, search, fetch
  • an optional agent brain, each part loaded only if you ask for it: long-term memory and a journal, a knowledge graph with a reasoner that proves its answers, think (tree of thoughts with verification), delegate (sub-agents), skills and steering files, chat history, a context guard that compacts long chats, and routers that pick the tools and the model for each turn
  • automation: n8n-style flows, Ansible-style playbooks (no model in the loop, approved by your app), Gantt plans, an autonomy queue (a 3-tier scheduler with budgets and approval gates), a heartbeat checklist, curiosity wake-ups, secrets, and Jade Lisp for DSLs
  • notes: an Obsidian-style vault on the file system: [[wiki links]], backlinks, #tags, search, renames that update links, daily notes and templates
  • senses and devices: HTTP with secrets, MCP servers, the camera, microphone, location and other sensors, look (the agent sees an image), WebUSB, and backups (gzip, optionally encrypted, to a file or a server)

Its pieces come from Jade Vault. The examples below use kit.<feature> after await kit.use('<feature>').
