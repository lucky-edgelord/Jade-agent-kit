sentry-engine.js

Source
src/sentry_engine.js
Size
4.2 KB gzipped (9.6 KB raw), with the chunks it imports

Sentry's rules engine: a JavaScript port of Jade's Rust engine (rust/core/src/sentry.rs), so a rule means the same on a phone and in a browser. No I/O and no clock of its own: every call carries now (ms) and the host drives it.

A trigger is { id, when?, on?, for_s, cooldown_s, max_per_hour, hours, rearm, ... }: - when is a state condition: all / any / not over leaves { src, op, value, clear }. A leaf with clear is a

 hysteresis band: it turns on at `value` and only turns off at `clear`, so a reading hovering at the threshold
 does not flap. Leaves: ops lt le gt ge eq ne in; { src: 'geo', op: 'inside'|'outside', lat, lon, radius_m, clear_m }.

- a state trigger (no on) fires on the edge, once its condition has held for for_s seconds; it fires again only

 after the condition clears (rearm "clear", the default) or the cooldown passes while it holds (rearm "cooldown").

- an event trigger (on: { event, where }) fires when a matching event arrives while when holds. - guards on both: cooldown_s, max_per_hour, and active hours ("22:00-07:00"). - after (re)configuring, a condition that is already true is a baseline, not an edge.

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.1.0/dist/sentry-engine.js';
