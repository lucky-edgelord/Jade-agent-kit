curiosity

Curiosity: the agent wakes at random times and chooses what to do, ranked by learning progress and its own track record (Schmidhuber's curiosity: reward the improvement of a predictor, not surprise). The reward is measured from what changed in the file system (new files, edited files, links in new notes, new memories), not from the agent's opinion, which only counts a little. <root>/CURIOSITY.md holds the user's wishes and limits. Ported from Jade Vault (app/modules/curiosity.js); the engine is unchanged.

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.0.0/dist/curiosity.js';
