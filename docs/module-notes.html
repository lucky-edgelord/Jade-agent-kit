Load

Tools
notes_search note_links note

Notes: an Obsidian-style knowledge base on the kit's file system. Notes are .md files anywhere (under root). [[wiki links]] (with |alias and #heading) and markdown links to .md files, backlinks, unresolved links, #tags and frontmatter tags, ranked search, daily notes, templates ({{title}}, {{date:YYYY-MM-DD}}, {{time}}, your own {{vars}}) and renames that update every link. The index rebuilds lazily when files change. Ported from Jade Vault (app/modules/vault_core.js).

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.0.0/dist/notes.js';
