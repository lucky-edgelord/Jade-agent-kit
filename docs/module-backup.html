backup

Backup: the whole file system (or a folder) as one file, gzip-compressed and optionally encrypted on this device (AES-GCM, key from a passphrase with PBKDF2), to download, keep, or send to a backup server (Jade Vault's server/jade-backup-server.py: PUT /backups/<name> with a bearer token and an X-Sha256 header). Restoring replaces or merges files. Secrets and approvals are never included (they are not in the file system). From Jade Vault (autobackup.js).

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.0.0/dist/backup.js';
