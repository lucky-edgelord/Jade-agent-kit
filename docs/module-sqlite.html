sqlite.js

Source
src/sqlite.js
Size
9.0 KB gzipped (21.1 KB raw), with the chunks it imports
Load
kit.use('sqlite')

SQLite 3.53 compiled to WebAssembly, with sqlite-vec (vector search: vec0 tables, vec_distance_cosine, …) and FTS5. Databases run in memory; a database opened from a VFS path is written back with db.save() (or on close()).

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.0.0/dist/sqlite.js';
