src/js.js
Size
13.3 KB gzipped (35.6 KB raw), with the chunks it imports
Load
kit.use('js')

Run JavaScript in a Web Worker with a Node-style sandbox: require('fs' | 'path' | 'util' | 'os' | 'http' | 'https' | 'node:sqlite' | 'better-sqlite3'), local modules (./lib.js), Buffer, process, and kit (alias jade) to call the kit's tools from a script. Files the script writes go back to the VFS.

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.0.0/dist/js.js';
