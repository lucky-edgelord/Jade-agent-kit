transformers

Transformers.js 4.3.2 (Hugging Face): models from the Hugging Face Hub running in the page, on WebGPU when the device has it, else WebAssembly. Downloaded from jsDelivr the first time it is used; models are cached by the browser.

const tf = await kit.use('transformers');
await tf.embed(['hello', 'world'])                         // [[…384 numbers], […]] (Xenova/all-MiniLM-L6-v2)
await tf.run('sentiment-analysis', 'I love it')            // any pipeline task, default or chosen model
await tf.run('automatic-speech-recognition', '/rec.wav', { model: 'Xenova/whisper-tiny.en' })

Embedding models named "hf:<repo>" work everywhere the kit embeds: kit.embed(x, { model: 'hf:Xenova/all-MiniLM-L6-v2' }), kit.vectors.open(path, { model: 'hf:…' }), createKit({ memory: { embed: 'hf:…' } }).

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.1.0/dist/transformers.js';
