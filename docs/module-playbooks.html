Tools
playbook

Playbooks: deterministic automation in the shape of Ansible, with no model in the loop. A playbook is JSON in <root>/<name>.json: { description, vars, allow_hosts, seconds, tasks: [ {name, do, …args, when, loop, register, retries, until, delay, failed_when, ignore_errors, timeout, tags, no_log} | {block, rescue, always} ] }. "do" is any kit tool ({"do": "bash", "command": "ls"}; "<tool>.<action>" for tools with actions) or a built-in action: set, debug, fail, assert, wait, save, playbook. Strings may hold {{ expressions }} over the variables and secrets. Approval: a playbook runs unattended (from flows, schedules, the autonomy queue or an agent) only once your app has approved it, and again after every change. Approvals are kept outside the file system, so an agent cannot approve its own playbook: call kit.playbooks.approve(name), or pass createKit({ playbooks: { approve: async info => bool } }). Ported from Jade Vault (app/modules/playbook.js); the engine is unchanged.

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.0.0/dist/playbooks.js';
