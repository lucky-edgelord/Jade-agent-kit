Features and sizes

Every feature is its own module, downloaded the first time kit.use(name) (or a helper such as kit.run()) needs it. Sizes are gzipped and include the shared chunks a module imports; runtimes that load from a CDN afterwards (MicroPython, SQLite's WebAssembly, TensorFlow.js, …) are extra. The core, createKit and the file system, is 6.6 KB.

FeatureModuleSizeAdds toolsWhat it is
kit.use('busybox')busybox.js5.0 KBBusyBox 1.37 compiled to WebAssembly (Emscripten).
kit.use('shell')shell.js12.6 KBThe shell as a public API: run command lines against the VFS.
kit.use('js')
also node, javascript		js.js13.3 KBRun JavaScript in a Web Worker with a Node-style sandbox: require('fs' | 'path' | 'util' | 'os' | 'http' | 'https' | 'node:sqlite' | 'better-sqlite3'), local modules (./lib.js), Buffer, process, and kit (alias jade) to call the kit's tools from a script.
kit.use('python')python.js8.5 KBMicroPython (the WebAssembly build PyScript uses) in a Web Worker.
kit.use('sqlite')
also db		sqlite.js9.0 KBSQLite 3.53 compiled to WebAssembly, with sqlite-vec (vector search: vec0 tables, vec_distance_cosine, …) and FTS5.
kit.use('bm25')bm25.js2.1 KBRanked keyword search: Okapi BM25 with the same scoring as Python's rank_bm25.BM25Okapi.
kit.use('ml')ml.js4.6 KBMachine learning runtimes, each downloaded from jsDelivr (pinned) the first time it is used.
kit.use('webxdc')webxdc.js9.2 KBA webxdc host (https://webxdc.org): run .xdc apps in a sandboxed iframe with window.webxdc.
kit.use('ollama')ollama.js2.2 KBOllama clients. One class for both places Ollama runs.
kit.use('vectors')vectors.js3.4 KBA vector store: texts embedded with Ollama, kept in SQLite with sqlite-vec, searched by meaning (and keywords).
kit.use('decisions')
also decide		decide.js4.6 KBDecisions: decision models judge a state against a question with calibrated probabilities (System One API, POST /v1/systemone).
kit.use('tasks')tasks.js1.3 KBA task list (a to-do list an agent plans with and a user can see), kept in the VFS at /.kit/tasks.json.
kit.use('cron')schedule.js5.1 KBA cron scheduler for the page: jobs run shell commands, JavaScript, Python, an agent prompt, or your own function, on a cron expression or plain English ("every weekday at 8:30", "in 20 minutes", "tomorrow at 7pm").
kit.use('schedule')
also schedules, scheduler		schedule.js5.1 KBA cron scheduler for the page: jobs run shell commands, JavaScript, Python, an agent prompt, or your own function, on a cron expression or plain English ("every weekday at 8:30", "in 20 minutes", "tomorrow at 7pm").
kit.use('sentry')sentry.js9.8 KBSentry for the browser: an event-driven "nervous system".
kit.use('tools')tools.js8.4 KBread write edit bash python javascript sqlite search_files search fetch decide tasks schedule sentry web_search web_fetchTool definitions for LLM agents, with one dispatcher.
kit.use('agent')agent.js2.3 KBA small coding agent in the style of pi: a model on Ollama (Cloud, or on a machine), a loop, and six tools — read, write, edit, bash (the kit's shell, with node / python / sqlite3), search and fetch (Ollama web search/fetch).
kit.use('memory')memory.js7.2 KBmemoryLong-term memory, in plain files an app (or its user) can read and edit: Search ranks lines with BM25; with { embed: 'embeddinggemma' } it also searches by meaning (Ollama + sqlite-vec).
kit.use('knowledge')
also kg		knowledge.js5.7 KBknowledgeA knowledge graph: facts like works_at(alice, acme), rules and constraints, and a reasoner that proves answers (✓ proven with the facts and rules it rests on, ✗ contradicted, ? unknown).
kit.use('think')think.js11.2 KBthinkthink: a tree of thoughts with verification.
kit.use('delegate')delegate.js3.8 KBdelegatedelegate: a sub-agent.
kit.use('skills')
also steering		skills.js5.4 KBskill find_skillSteering and skills, in files (pi style): With many skills (more than allMax), each prompt lists only the ones that best fit the message, and the agent gets a find_skill tool for the rest (BM25 on name + description; with { embed } also by meaning).
kit.use('history')
also chats		history.js5.5 KBchat_historyChat history: saved conversations (the raw messages, not summaries), listed, read and searched.
kit.use('guard')
also context		guard.js4.0 KBContext guard: keep every request inside the model's context window.
kit.use('router')
also tool-router		router.js4.4 KBmore_toolsRouters. Each saves context or money on every turn, and each can be left out.
kit.use('secrets')secrets.js2.8 KBsecretsSecrets: API keys, tokens and passwords your app gives the kit, for playbooks ({{ secrets.NAME }}) and HTTP requests.
kit.use('flows')
also flow		flows.js15.9 KBflowFlows: small n8n-style automations.
kit.use('playbooks')
also playbook		playbooks.js15.3 KBplaybookPlaybooks: deterministic automation in the shape of Ansible, with no model in the loop.
kit.use('gantt')
also plans		gantt.js4.7 KBganttPlans: Gantt charts for long-term projects.
kit.use('autonomy')
also sched, queue		autonomy.js6.5 KBautonomyAutonomy: a 3-tier scheduler (like an operating system's multilevel feedback queue) and an autonomous mode.
kit.use('heartbeat')heartbeat.js2.2 KBheartbeatHeartbeat: every N minutes inside active hours, an agent reads <path> (HEARTBEAT.md, a short checklist) and acts on it.
kit.use('curiosity')curiosity.js6.0 KBcuriosityCuriosity: the agent wakes at random times and chooses what to do, ranked by learning progress and its own track record (Schmidhuber's curiosity: reward the improvement of a predictor, not surprise).
kit.use('lisp')lisp.js3.2 KBlispJade Lisp: a small Scheme/Clojure-style Lisp for DSLs and for scripting the kit's tools, from Jade Vault.
kit.use('notes')notes.js6.3 KBnotes_search note_links noteNotes: an Obsidian-style knowledge base on the kit's file system.
kit.use('http')http.js3.2 KBhttphttp: requests for agents and scripts (GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS) with the kit's secrets.
kit.use('mcp')mcp.js5.0 KBmcpMCP: connect to Model Context Protocol servers over streamable HTTP (a browser cannot start stdio servers) and use their tools and resources.
kit.use('senses')senses.js4.1 KBsenses lookSenses: the browser's camera, microphone, location, motion sensors, battery, network and device facts, for apps and agents; and look, which shows the agent an image from the file system.
kit.use('usb')usb.js2.2 KBusbusb: USB devices through WebUSB (Chrome and Edge, on https or localhost).
kit.use('backup')backup.js3.1 KBbackupBackup: the whole file system (or a folder) as one file, gzip-compressed and optionally encrypted on this device (AES-GCM, key from a passphrase with PBKDF2), to download, keep, or send to a backup…
kit.use('models')
also model-router		router.js4.4 KBRouters. Each saves context or money on every turn, and each can be left out.

The sizes come from the build, so they are always those of v3.0.0. For loading only what you need, see Lean loading.
