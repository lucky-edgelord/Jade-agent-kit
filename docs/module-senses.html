Tools
senses look

Senses: the browser's camera, microphone, location, motion sensors, battery, network and device facts, for apps and agents; and look, which shows the agent an image from the file system. Sensitive senses (camera, microphone, location) work only when your app allows them: createKit({ senses: { allow: ['camera', 'microphone', 'location'] } }) or kit.senses.allow('camera'), and the browser still asks the user. Ported from Jade Vault (world.js), browser side.

On its own, without createKit:

import * as m from 'https://cdn.jsdelivr.net/gh/lucky-edgelord/Jade-agent-kit@v3.1.0/dist/senses.js';
