  • Things to know
  • Development
  • License
  • Changelog
  • Browser support: a current Chrome, Edge, Firefox or Safari. Needs Web Workers, WebAssembly and DecompressionStream. WebGPU is optional.
  • Content-Security-Policy: the shell, Python and JS run in workers made from blob: URLs (worker-src blob:), WebAssembly needs 'wasm-unsafe-eval', and the runtimes come from cdn.jsdelivr.net unless you host them.
  • Sandboxing: scripts run in Web Workers of your page's origin. They cannot touch the page or its DOM, but they can make network requests as your page (pass network: false to kit.js.run to turn that off). webxdc apps are isolated in a sandboxed frame. Treat the kit as a workspace, not a security boundary against hostile code.
  • API keys: an Ollama Cloud key used in a browser is visible to whoever uses that page. Use it in your own tools, or put a small proxy in front of https://ollama.com and set kit.ollama.host to it.
  • Ollama and Ollaya on your machine: a web page may only call them when they allow the page's origin. Start them with OLLAMA_ORIGINS="https://your.site" ollama serve / OLLAYA_ORIGINS=… ollaya serve (or "*"). Chrome may also ask the user to allow local network access the first time.
  • Big files: files over 16 MB are not copied into BusyBox commands, over 4 MB into Python and over 2 MB into JS scripts (SQLite databases excepted).
